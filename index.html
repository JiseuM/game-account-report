三条关键结论

  1. 7881 的「我要卖」不是发布表单，而是估价漏斗。入口为 首页宫格「我要卖」→ /pages/account-valuation/home「免费账号估价」→ 选游戏 → 底部「选择游戏区服」（运营商 QQ/微信 → 区服 安卓QQ/苹果QQ/抢先一区…）→ 下一步。王者荣耀分支落到「营地ID」页，无畏契约手游分支落到「QQ 扫码估价」页——同一入口、两套准入，均无法在无授权状态下继续。
  2. 7881 的加载态是可复现的前端死状态。5 位数字（12345）与合法 11 位（已打码）都在点击后立即进入全屏「获取账号信息中」，无取消、无关闭、无超时；15 秒 / 60 秒 Network 观测均无任何业务请求。这不是慢，是没发出。
  3. 螃蟹的最低代售费按游戏分档，且页面不解释。同为「费率5%，最低…」，王者荣耀最低 50 元、无畏契约与超自然行动组最低 30 元；超自然售价 31 元时到手仅 1 元（抽走 96.8%），王者荣耀 80 元时到手 30 元。价格下限也不同：王者 ≥80、无畏契约 ≥60、超自然 ≥31。
本轮与前序记录的差异：① 7881「我要卖」的真实落点被确认为「免费账号估价」而非发布表单（此前从发布页直接进入）；② 7881 存在「扫码估价」分支（无畏契约手游），二维码有效期 2 分钟、微信需双设备；③ 未扫码点「扫码登录后点击此处」，页面直接暴露后端英文报错 Required Long parameter 'taskId' is not present；④ 螃蟹最低代售费非全局 30 元，王者荣耀为 50 元。

02入口与准入

本页评价 · 5 分制
78812.5盼之3.2螃蟹4.0

7881 需要「估价漏斗 + 游戏分支差异化授权」两步才能靠近表单，路径最长；盼之两步到位但授权即 404；螃蟹从选游戏直达表单，授权前置说明清楚。

7881：估价漏斗替代发布入口

  1. 首页功能宫格第 3 项「我要卖」→ /pages/account-valuation/home「免费账号估价」（含「免费AI智能估价」「人工在线估价」两块）。
  2. 点游戏格（如王者荣耀）→ 底部弹出「选择游戏区服」：左列「运营商」= QQ / 微信，右列「区服」= 安卓QQ / 苹果QQ / 安卓Q抢先一区 / 安卓Q抢先二区；未选区服时「下一步」默认可走（落到安卓QQ·全服）。
  3. 王者荣耀 → quick-valuation?...gameName=王者荣耀&carrierName=安卓QQ&serverName=全服：页面为「营地ID」+ 4 条温馨提示；无登录态、无实名、无保证金提示。
  4. 无畏契约手游 → 同一位置变为「QQ扫码估价」：二维码 2 分钟有效，需本人常用 QQ/微信扫码，微信需双设备；并明确「仅登录掌上无畏契约APP」。
游戏目录缺口：7881 估价页首屏共 18 款游戏，不含「超自然行动组」；该页仅有区服搜索，没有全站游戏搜索入口。因此 7881 对超自然行动组的卖号链路本轮无法进入（未验证），不推断为「不支持」。

盼之：两步到表单，授权即出口

进入即 /sell/releaseV2?type=0，页头卡片为「王者荣耀 成品号 · QQ 安卓QQ」，可展开切换账号类型与操作系统；准入仅要求「截图方式（上号截图，只读）+ 游戏账号 + 授权上号」，无实名、无保证金提示，但提示「需QQ扫码授权，期间勿登录游戏，防止挤号中断」。

螃蟹：选游戏直达表单

/pages-center/SelectGame/index（全部/手游/端游 + 最近浏览 + 热门推荐）→ 点游戏 → SellAccount?... 表单。王者荣耀分支注明「点击发布后建议扫码上号」；超自然行动组注明「授权过程加密处理」，但游戏密码输入框为明文。

08结论与建议

本页评价 · 5 分制（结论可用性）
78812.0盼之2.8螃蟹4.1

三条可直接转化为 7881 改造项：把估价漏斗与发布表单拆清、给加载态加超时与出口、把后端异常收口成用户文案；同时抄螃蟹的费用联动、避开其对比度与分档费率坑。

对 7881 的建议

  1. 打通「估价 → 发布」的显式路径：当前「我要卖」落到估价页，用户不知道估价完成后能否直接上架。建议在估价结果页提供「按此估价发布」按钮，并回显已选游戏/区服，减少重复选择。
  2. 给「获取账号信息中」加超时与出口：本轮 60 秒 0 请求，说明请求根本没发出。必须加 8–10 秒超时、失败重试、取消按钮，并在遮罩上显示「正在读取账号信息…」以外的进度信息。
  3. 补齐营地ID 位数校验：maxlength 140 无意义，建议 8–12 位数字实时校验 + 明确错误文案；不要等提交后才用遮罩拦截。
